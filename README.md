# Tunuino KiCad Library

Biblioteca de símbolos, footprints e modelos 3D para os projetos eletrónicos Tunuino.

## Estado

A biblioteca foi importada e integrada no repositório principal através do submódulo `hardware/tunuino-kicad-library`. A pasta de footprints é `tunuino_lib.pretty`. Os footprints de logótipos de outros projetos foram removidos.

**A compatibilidade completa com KiCad 9 ainda não foi validada.** Alguns ficheiros usam formatos legados de KiCad (`.lib`, `.mod` e `(module ...)`), que podem exigir conversão na aplicação.

## Integração

Validar os símbolos, footprints, modelos 3D e scripts de fabrico antes de utilizar esta biblioteca para fabricar uma PCB.
